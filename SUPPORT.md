# iADB Support

Open a support request in [GitHub Issues](https://github.com/h33h/iadb-ios/issues).

Include:

- iADB version
- iOS or iPadOS version
- Android version and device model
- the feature you were using
- the exact error shown by iADB
- steps that reproduce the problem

Do not post pairing codes, ADB keys, serial numbers, private IP addresses,
personal file names, installed-app lists, or unredacted Logcat output. Replace
those values with fictional examples before attaching a screenshot or log.

For privacy questions, read the [Privacy Policy](PRIVACY.md) before opening an
issue.
