iADB connects your iPhone or iPad to an Android 11+ device over local Wi-Fi. Pair with the code shown in Android Settings, then use native tools for routine diagnostics and device management.

Features:
• Discover, pair, connect, and reconnect to nearby devices
• Review device, battery, memory, display, and build details
• Browse, preview, upload, download, rename, move, duplicate, and delete files
• Search packages, inspect details, install APK files, launch or stop apps, clear app data, and uninstall packages
• Run shell commands with history, pinned commands, and shortcuts
• Stream, filter, save presets, and export Logcat
• Capture screenshots and save them in iADB or Photos

iADB sends commands and files to the Android device you choose and receives device data over the same local connection. Exports and Photos saves occur when you request them. The app has no account, ads, analytics, or developer-operated server.

Use iADB only with devices you own or are authorized to manage.

Requirements:
• Android 11 or later
• Wireless Debugging enabled
• Both devices on the same local network
